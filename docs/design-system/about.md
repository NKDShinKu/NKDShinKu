# 页面设计 — 关于页（M3）

> 本文件是 `docs/design-system.md` §0 约定的**页面覆盖文件**：构建 `/about` 时，本文档规则覆盖主文档的页面级决策；token / 基础组件 / 无障碍与响应式纪律仍以主文档为准。
> 对应需求：REQ-A1（P1）、REQ-A2（P2）、REQ-F3（订阅入口）、REQ-G4。
> 设计方向（manifest D16）：**站点事实卡**路线——页面主角是「这个站点」而非「我的履历」：站名由来 / 理念 / 技术栈 / 站点状态等事实卡为主体，REQ-A1 个人内容收敛为紧凑区块；个性化记忆点放在卡片文案与小组件，而非个人档案墙。
> 内容素材（开放问题 O3）：站名由来/理念文案、自我介绍、技能栈由用户提供；落地时先占位、后替换。

## 1. 设计决策总览

| #    | 决策点     | 结论                                                                                                                              |
| ---- | ---------- | --------------------------------------------------------------------------------------------------------------------------------- |
| A-1  | 页面主角   | 「站点」事实卡为主体（D16）；个人介绍收敛为一个紧凑区块（A-6），不放档案墙/兴趣墙                                                |
| A-2  | 页面背景   | 主文档 §3.2 无关于页专属背景条目——沿用全局极光/萤火（同实验室页 L-1，弱化氛围，本页不新增背景层）                                 |
| A-3  | 卡片材质   | 事实卡**实心 surface**（主文档 §1.6）；唯一玻璃态例外：页头问候面板（氛围区，文字稀疏）                                          |
| A-4  | 事实卡形式 | kloudy 式「键值对卡」：卡 = 小标题（图标 + 标签）+ 一个主值 + 一句说明；卡片小而多，2–3 列网格                                   |
| A-5  | 个性化记忆点 | ① 站名由来卡（一句话故事）② 字数换算小部件（M2 已有字数统计能力可派生：写作量 ≈ N 个中篇）③ 建站时间线（4 行：萌生/动工/上线/现在） |
| A-6  | 个人区块   | 页头下方一个横向紧凑卡：头像 + 一句话人设 + 社交/联系图标行（复用页脚 socials 配置，`site.config` 单一来源）+ 订阅入口           |
| A-7  | 动效       | 事实卡 `Reveal subtle` stagger 0.04；页头问候面板 GSAP 入场（power3.out，同 Hero 语系但更轻）；无 hover 抬升（非交互卡）        |
| A-8  | 数据来源   | 所有「事实」（技术栈/上线天数/字数）从 `site.config` / `lib/` 派生或集中配置，**页面零硬编码**，避免文案腐化                     |

## 2. 新增组件规范

> 均为自研组件，文件落位 `src/components/about/`；样式全用工具类，禁止裸 hex。

### 2.1 FactCard 事实卡（A-4 核心组件）

```
┌────────────────────────┐
│ ◆ 站名由来              │   图标 size-4 text-accent + 标签 text-xs uppercase tracking-widest muted
│ NKDShinKu              │   主值 font-display text-lg font-bold text-text
│ 一句话说明文案……       │   text-sm text-text-muted line-clamp-2
└────────────────────────┘
```

- `Card variant="surface"`（非交互，无 hover 抬升），`p-5`；网格单元 `grid gap-4 sm:grid-cols-2 lg:grid-cols-3`。
- 主值可以是文字、标签组（技术栈卡）或小组件（字数卡 A-5）。
- 卡片清单（首版 6 张，文案占位待 O3）：

| 卡         | 内容来源 / 占位                                                      | 图标                        |
| ---------- | -------------------------------------------------------------------- | --------------------------- |
| 站名由来   | 用户提供一句话（占位：ShinKu 的含义/来源）                          | `mdi--book-open-variant`    |
| 理念       | 用户提供（占位：写下来才算学会）                                    | `mdi--lightbulb-outline`    |
| 网站类型   | 个人技术博客（ACG 气质）                                             | `mdi--web`                  |
| 技术栈     | 标签组：Next.js / React / Tailwind / TS（`site.config` 派生或常量） | `mdi--wrench-outline`       |
| 站点状态   | 「持续建设中」+ 最近部署/内容更新时间                                | `mdi--progress-clock`       |
| 写作字数   | 小部件：全站文章字数 ≈ N 本《XX》（M2 字数统计派生）                | `mdi--pencil-outline`       |

### 2.2 页头问候面板（A-3，唯一玻璃卡）

```
┌──────────────────────────────────────┐
│  你好，我是 NKDShinKu 👋（不用 emoji， │   h1 font-display text-2xl md:text-3xl
│  [头像]  一句话人设                    │   头像 rounded-full size-16/20，alt 必填
│  [GitHub][邮箱][Bangumi][QQ][RSS]     │   图标行 44px 触控，aria-label
└──────────────────────────────────────┘
```

- 玻璃卡 `backdrop-blur-md`（§1.6 规范值）；`p-6 md:p-8`；头像与人设横排（移动端纵排）。
- 社交行复用 `siteConfig.socials` + 追加 RSS（`/feed.xml`，REQ-F3）；图标按钮 `size-11`。
- 一句话人设（REQ-A1 摘要）：用户占位文案；`text-text-muted text-sm md:text-base`。

### 2.3 建站时间线（A-5）

- 复用归档页时间线视觉（posts.md §2.9）：`border-l-2 border-border pl-6`，圆点 `bg-accent-light`。
- 首版 4 行（内容可后补）：萌生想法（2026-08 前后）/ 动工（2026-08）/ 上线（2026-08/09）/ 现在（持续写作中）。
- 行内容：日期（`font-mono text-xs text-text-muted`）+ 事件文案（`text-sm`）。

### 2.4 技能/关于我区块（REQ-A1 收敛）

- 不做技能进度条墙（反模式）；形式 = 一个「关于我」小节：`prose` 短文（2–3 段，用户素材）+ 技能 Tag 行（`bg-accent/10 text-accent-dark` 徽章，复用 Tag）。
- 落位在事实卡网格之后、时间线之前；无卡包装、直接 prose（阅读区纪律：实心底 + 恰当行长 `max-w-[720px]`）。

  页头问候面板（玻璃卡，§2.2）

## 4. 动效（接主文档 §3.3）

| 场景         | 方式        | 参数                            |
| ------------ | ----------- | ------------------------------- |
| 问候面板入场 | GSAP        | 600ms power3.out（轻量 Hero）   |
| 事实卡入场   | GSAP Reveal | 400ms power2.out，stagger 0.04  |
| 时间线入场   | GSAP Reveal | 600ms power2.out                |
| 社交图标 hover | CSS       | 150ms（色变 + 轻抬升）          |

`prefers-reduced-motion: reduce` 全部禁用（Reveal 已守卫）。

## 5. 响应式与无障碍要点（本板块增量）

- 断点行为：`<640px` 事实卡 1 列 / 头像纵排；`≥640px` 2 列；`≥1024px` 3 列。
- 头像 `alt` 必填（O3 素材到位前用站点 logo 兜底 + `alt="NKDShinKu 头像"`）。
- 社交图标按钮 `aria-label`（「GitHub 主页」「发送邮件」等）+ `focus-visible` ring；触控 ≥ 44px。
- 事实卡非交互：**不包 Link、不加 hover 位移**，仅图标装饰 `aria-hidden`。
- 时间线行非交互，无 focus 需求。
- 对比度：事实卡主值/说明走 `text`/`text-muted`（主文档纪律）；卡片图标可用 `text-accent`。
