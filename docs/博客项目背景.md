# 我的博客方向

## 我的想法

我想完成一个二次元风现代个人技术博客，里面有二次元插图或背景透视（不多）。这个博客用于记录个人文章、教程、实验室 / 个人项目、日常、二次元 / 追番（接入外部bangumi api）等内容。我认为可以发挥创造性，这不仅仅是给别人看的，而主要是展示自己的成果。在页面设计、风格、排版上面都要精致。

## 博客设计风格方向

想要acg的感觉，但“不要太过”。核心魅力其实不在于满屏幕放二次元图片，而在于它的排版、配色、微透视和交互。

- 主要为蓝（天蓝/清澈蓝）白配色，可以有其他颜色
- 黏土质感风格：具体查看 docs\design\黏土质感风格参考.md（暂定，仅作参考，不知道是否合适）
- 滚动叙事：具体查看 docs\design\滚动叙事参考.md（暂定，仅作参考，不知道是否合适）

> design-system\文件是以前使用ui-ux-pro-max生成的设计方案，有需要可以参考
