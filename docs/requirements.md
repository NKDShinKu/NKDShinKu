# 博客需求清单（Requirements）

> 本文件只回答「要什么」：功能、体验、风格诉求。
> 实现方式（选型/决策/风险）见 `docs/project-manifest.md`；进度见 `docs/roadmap.md`；
> 内容格式约定见 `content/README.md`；协作规则见 `AGENTS.md`。
> 需求编号：`REQ-<域>-<序号>`；优先级：**P0** 上线必备 / **P1** 首版应有 / **P2** 后续迭代 / **P3** 暂缓（默认不做，重启需用户确认）。

## 1. 定位与目标

- 一个 **ACG 风现代个人技术博客**，首要目的**展示自己的成果**，其次面向读者。
- 内容板块：文章（教程 / 技术笔记 / 日常）、实验室（外链项目 + 站内 demo/工具/实验）、追番、关于。

## 2. 非目标（明确不做，除非用户重新提出）

- 用户系统、登录、后台管理界面
- 多语言 / i18n（仅中文）
- 友链页面、访问统计
- 实时聊天、弹幕、视频播放等重交互功能
- 文章付费 / 打赏

## 3. 用户与核心场景

| 用户             | 诉求                                  |
| ---------------- | ------------------------------------- |
| 博主本人（首要） | 沉淀产出、展示成果、记录追番与日常    |
| 技术读者         | 找教程/文章、搜索与筛选、良好阅读体验 |
| 同好访客         | 浏览追番与日常、了解博主              |
| 访客（玩心起）   | 在实验室直接体验站内 demo / 小工具    |

核心场景：写文章 → 访客从首页/搜索/分类进入阅读 → 看实验室条目（跳转仓库或站内体验 demo）→ 看追番进度与评分。

## 4. 信息架构

导航：**首页 · 文章 · 实验室 · 追番 · 关于**（页头主导航为文章/实验室/追番/关于，首页由 logo 返回；页脚为社交/联系入口）。

| 板块     | 路径                                     | 说明                                     |
| -------- | ---------------------------------------- | ---------------------------------------- |
| 首页     | `/`                                      | hero + 最新文章 + 板块入口               |
| 文章     | `/posts`                                 | 教程/笔记/日常合并，日常是文章的一个分类 |
| 文章详情 | `/posts/[slug]`                          |                                          |
| 分类     | `/posts/category/[cat]`                  | 教程 / 笔记 / 日常（可扩展）             |
| 标签     | `/posts/tag/[tag]`                       | 自由标签                                 |
| 归档     | `/archive`                               | 按年份分组                               |
| 实验室   | `/lab`                                   | 条目卡：外链项目 + 站内 demo/工具/实验   |
| 实验室条目 | `/lab/[slug]`                          | 站内可看的 demo / 小工具页               |
| 追番     | `/bangumi`                               | Bangumi 收藏数据展示                     |
| 关于     | `/about`                                 | 个人介绍、技能、联系方式                 |
| 搜索     | 页头弹窗（无独立路由）                   | 全站文章搜索，结果直达文章详情           |
| 订阅     | `/feed.xml` `/sitemap.xml` `/robots.txt` | RSS / 站点地图 / robots                  |

## 6. 非功能需求

| 类别   | 要求                                                                            |
| ------ | ------------------------------------------------------------------------------- |
| 性能   | 全静态、加载快；图片懒加载 + 显式宽高；首屏轻量                                 |
| 无障碍 | 键盘可达、对比度达标、可见焦点、触控目标够大、alt 必填、动效尊重 reduced-motion |
| SEO    | 每页独立元信息、canonical、结构化数据、sitemap、RSS                             |
| 隐私   | 无第三方统计、无 Cookie 追踪                                                    |
| 兼容   | 近两年主流浏览器（Chrome/Edge/Firefox/Safari，桌面 + 移动）                     |
| 安全   | 公开仓库，不泄露任何密钥                                                        |

## 7. 设计风格诉求

> 视觉方向与设计 token 已由 M1 设计定稿产出，落于 `docs/design-system.md`（本节省略具体视觉规范）。
> 设计工作流见 `AGENTS.md` §5。

**用户原话**：现代个人技术博客，浅色风格、蓝白配色、柔和阴影、圆润、轻微 ACG 背景与轻科技氛围，整体清新、专业、轻量且具有二次元气质；白天/夜间双主题，关键词：**天空、夜空**。

- 定稿风格：**Soft ACG Fusion**（玻璃态 × 极光背景 × 动效），配色「天蓝 × 樱粉 × 暮紫」，详见 `docs/design-system.md`。
- 二次元素材克制使用，排版 / 配色 / 微透视 / 交互优先。
- 旧设计归档（`docs/archive/design-system-old/`）已被 `docs/design-system.md` 取代，仅作历史参考。
