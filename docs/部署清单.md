# 部署清单（手工步骤）

> CI 流水线（`.github/workflows/deploy.yml`）已就绪；以下平台配置需手工完成。
> 完成一项勾一项 `[ ]` → `[x]`。

## 1. GitHub Pages + 自定义域名（上线时执行）

- [ ] 仓库 Settings → Pages → Source 选择 **GitHub Actions**（否则 deploy 任务会失败）
- [ ] Cloudflare DNS 添加记录（二选一）：
  - **CNAME 方案**：`nkdshinku.com` → `NKDShinKu.github.io`（Cloudflare 会自动拍平 apex CNAME）
  - **A 记录方案**（Cloudflare 代理关闭或"仅 DNS"）：
    `185.199.108.153` / `185.199.109.153` / `185.199.110.153` / `185.199.111.153`
- [ ] 仓库 Settings → Pages → Custom domain 填写 `nkdshinku.com` 并保存
- [ ] 等待 DNS 生效 + HTTPS 证书签发（几分钟~几小时），然后勾选 **Enforce HTTPS**
- [ ] 推送 `main` 分支触发首次部署；部署成功后验证：
  - 首页可访问 `https://nkdshinku.com`
  - 404 页生效（访问一个不存在路径）
  - Pagefind 产物存在 `https://nkdshinku.com/pagefind/pagefind.js`
- [ ] 本地 `git remote -v` 确认远端为 `NKDShinKu/NKDShinKu`（已确认 ✓）

## 2. Cloudflare R2 图床（路线图 M4 前完成）

- [ ] Cloudflare 控制台 → R2 → 创建存储桶（如 `nkdshinku-images`）
- [ ] 绑定自定义域：`static.nkdshinku.com` → 该存储桶（CNAME 自动配置）
- [ ] 创建 API Token（对象读/写权限），本地安装 rclone 并配置 S3 兼容端点为 R2
- [ ] 约定目录：`/images/posts/`、`/images/projects/`；上传后公网 URL 为
      `https://static.nkdshinku.com/images/...`（文章 frontmatter 的 `cover` 字段按此填写）
- [ ] 测试：浏览器直接打开一张图片 URL，确认可访问、Cache-Control 正常

## 3. giscus 评论（路线图 M3/M4 再启用）

- [ ] 仓库 Settings → 勾选 **Discussions**（Features 中开启）
- [ ] 安装 [giscus App](https://github.com/apps/giscus) 并授权 `NKDShinKu/NKDShinKu`
- [ ] 在 [giscus.app](https://giscus.app) 生成配置，记录 `repoId`、`categoryId`
- [ ] 配置写入 `src/lib/site.config.ts`（不要写进仓库外的秘密，giscus 配置本身是公开的）
- [ ] 实测国内网络下评论加载与提交（决定是否保留 giscus）

## 4. Bangumi（路线图 M3）

- [ ] 注册/登录 bangumi.tv，获取自己的用户 ID（个人主页 URL 中数字）
- [ ] 浏览器实测 `https://api.bgm.tv/v0/users/<id>/collections` 的 CORS 可用性
- [ ] 若跨域受限：按方案评估"风险 1"的备选路径决策
