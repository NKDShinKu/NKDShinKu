# NKDShinKu

个人技术博客与作品集。记录前端开发学习、项目实践与二次元追番足迹。

**设计风格：** Soft ACG Fusion — 玻璃态 × 极光渐变 × 轻二次元，通透、克制。

## 技术栈

Vue 3 + TypeScript + TailwindCSS v4 + GSAP 3 + marked

## 本地运行

```bash
npm install
npm run dev        # localhost:5173
npm run build      # 生产构建
```

## 目录

```
src/
├── pages/         # 页面组件（home / blog / projects / anime）
├── components/    # 通用 + 业务组件
├── stores/        # Pinia 状态管理
├── content/       # Markdown 文章
├── types/         # TypeScript 类型定义
└── router/        # 路由配置
design-system/     # 设计系统文档 + 视觉预览
```
